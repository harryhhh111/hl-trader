## 执行方式

使用现有 `compose.yaml`、`compose.managed-wallets.yaml` 和本机秘密环境文件构建镜像，随后执行：

```sh
docker compose --env-file .runtime/docker.env \
  -f compose.yaml -f compose.managed-wallets.yaml \
  up -d --no-deps --force-recreate --timeout 60 \
  --wait --wait-timeout 120 web worker gateway
```

重启前只读检查进行中的托管执行请求数为 0。`--no-deps` 跳过 migration、数据库授权和密钥初始化服务；已有数据库、回执卷、钱包密钥卷继续使用。本次没有发送订单或修改交易所保证金设置。

发现本机环境文件的认证模式与运行中容器不一致：文件为 `cloudflare_access`，运行中为 `account`。已将 `.runtime/docker.env` 的 `HL_APP_AUTH_MODE` 同步为 `account`，保持原有账号登录行为，其他环境项保持原值。
